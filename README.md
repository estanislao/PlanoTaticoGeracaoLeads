# Plano Tático de Geração de Leads — HupData

Site estático com acesso por senha (arquivos criptografados com AES via StatiCrypt; a descriptografia acontece no navegador).

| Arquivo | Acesso |
|---|---|
| `index.html` | Página inicial com os três botões — senha interna |
| `plano-tatico.html` | Plano completo — senha interna |
| `apresentacao-executiva.html` | Apresentação executiva — senha interna |
| `proposta-querri.html` | Proposta à Querri — senha própria |

Publicação: GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
URL: https://estanislao.github.io/PlanoTaticoGeracaoLeads/

Este repositório contém **apenas** as versões criptografadas. Os originais sem senha não devem ser versionados.
